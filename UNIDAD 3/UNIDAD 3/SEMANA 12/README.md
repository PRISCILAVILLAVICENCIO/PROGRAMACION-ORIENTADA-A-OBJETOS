
# 🏛️ Gestor de Biblioteca Literaria (CLI)

Este proyecto es una herramienta de Interfaz de Línea de Comandos (CLI) construida en Python para llevar el control absoluto de un catálogo literario y sus lectores. 

A través de una arquitectura sólida basada en clases y manejo de archivos JSON (texto plano), el sistema asegura que la información nunca se pierda.

---

## 🌟 Lo que este sistema puede hacer

* **Autoguardado Seguro:** Cada vez que haces un movimiento, el estado de la biblioteca se respalda en `registro_biblioteca.txt`.
* **Inventario Dinámico:** Incorpora nuevas obras o consulta las existentes filtrando por título, creador o género literario.
* **Control de Lectores:** Registra nuevas personas y supervisa exactamente qué materiales literarios tienen retirados.
* **Transacciones Literarias:** Asigna préstamos y recibe devoluciones actualizando el catálogo en tiempo real.
* **Datos de Prueba Incorporados:** Arranca automáticamente con un set de libros clásicos para probar el entorno de inmediato.

## 💻 Instrucciones de Despliegue

Es muy fácil ponerlo a funcionar. Solo necesitas tener **Python** instalado en tu sistema. 

1. Abre tu terminal (Símbolo del sistema, PowerShell o Bash).
2. Dirígete a la ruta donde guardaste el archivo del código fuente.
3. Ejecuta el archivo principal
